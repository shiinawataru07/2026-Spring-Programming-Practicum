01:反向输出一个三位数

📖 介绍
将一个三位数反向输出。

📝 题目要求

输入：一个三位数 n。

输出：反向输出 n。

02:字符串中的整数求和

📖 介绍
输入两个长度为3的字符串，每个串前两个字符是数字,后一个字符是字母。 求这两个串中的整数的和。

📝 题目要求

输入：一行，两个字符串。

输出：两个字符串中整数的和。

03:点和正方形的关系

📖 介绍
有一个正方形，四个角的坐标 (x,y) 分别是 (1,-1)，(1,1)，(-1,-1)，(-1,1)，x 是横轴，y 是纵轴。写一个程序，判断一个给定的点是否在这个正方形内（包括正方形边界）。

📝 题目要求

输入：输入一行，包括两个整数 x、y，以一个空格分开，表示坐标 (x,y)。

输出：输出一行，如果点在正方形内，则输出 yes，否则输出 no。

04:简单计算器

📖 介绍
一个最简单的计算器，支持 +, -, *, / 四种运算。仅需考虑输入输出为整数的情况（除法结果就是商，忽略余数）。

📝 题目要求

输入：输入只有一行，共有三个参数，其中第1、2个参数为整数，第3个参数为操作符（+, -, *, /）。

输出：输出只有一行，一个整数，为运算结果。然而：
    如果出现除数为0的情况，则输出：Divided by zero!
    如果出现无效的操作符(即不为 +, -, *, / 之一），则输出：Invalid operator!

05:围栏

📖 介绍
小 A 打算新建一幢楼，这幢楼需要占用一块长方形的面积恰好为 n 平方米的土地，且为了方便测量，这块土地的长宽必须为整数米。

小 A 需要在这幢楼外边修围栏，围栏长度为这块长方形的周长。

现在想要知道最小的围栏长度。

📝 题目要求

输入：第一行一个正整数 n (n le 2 times 10^9)，表示楼的面积。

输出：一行一个数表示答案。数据保证答案在 int 范围内。
